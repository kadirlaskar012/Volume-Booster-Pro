2. STORE LISTING — DETAILED DESCRIPTION (COPY & PASTE READY)

Are quiet videos on YouTube, Netflix, or Spotify ruining your listening experience?

Volume Booster Pro is a lightweight, ultra-powerful Chrome extension that lets you amplify browser audio up to 600% (6× baseline volume) with crystal-clear fidelity. Powered by the native Web Audio API, Volume Booster Pro transforms your laptop speakers or headphones into a high-grade audio powerhouse.

From quiet speech in Zoom meetings and podcasts to thumping EDM tracks and immersive movies, Volume Booster Pro gives you complete mastery over your sound.

✨ KEY FEATURES & HIGHLIGHTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔊 UP TO 600% AUDIO AMPLIFICATION
• Amplify any media tab beyond the standard 100% volume ceiling.
• Clean, transparent gain staging powered by Web Audio API GainNode.
• Instant 1-click presets: 100% (1×), 150% (1.5×), 200% (2×), 300% (3×), 400% (4×), and 600% (6×).

🛡️ INTELLIGENT SOFT-KNEE SAFETY LIMITER
• Built-in dynamic compression prevents speaker distortion and clipping.
• Protects your ears and device hardware even at extreme boost levels.

🎵 4 TAILORED DSP SOUND PROFILES (EQ)
• 🎧 Balanced: Studio-grade neutral acoustic tuning for everyday listening.
• 🔊 Bass Boost: Punchy low-end punch engineered for EDM, Hip-Hop, and trap beats.
• 🗣️ Vocal Clear: Enhanced dialogue presence for podcasts, audiobooks, lectures, and calls.
• 🎬 Cinema 3D: Wide spatial soundstage bringing movies, series, and games to life.

⚡ DEDICATED SUB-BASS BOOSTER (+0 TO +15 dB)
• Dedicated Low-Shelf DSP filter tuned at 80Hz.
• Feel the deep sub-bass rumble on laptop speakers, monitors, and headphones.
• Smooth granular slider for pinpoint low-frequency control.

🌓 DYNAMIC LIGHT & DARK THEME ENGINE
• 🌙 Sleek Midnight Dark Mode for low-light environments and OLED screens.
• ☀️ Crisp, high-contrast Light Mode for bright daytime productivity.
• 1-Click instant toggle with persistent memory across browser restarts.

🎚️ PRO AUDIO FX & STEREO PANNER
• L / R Stereo Balance slider to fix unbalanced recordings or accommodate hearing preferences.
• 1-Click Center reset button.

⌨️ GLOBAL KEYBOARD SHORTCUTS
• Press Ctrl + Shift + Up Arrow (Command + Shift + Up on Mac) to boost volume.
• Press Ctrl + Shift + Down Arrow (Command + Shift + Down on Mac) to lower volume.
• Control sound instantly without ever clicking or opening the popup.

🔒 100% PRIVACY & CLIENT-SIDE SECURITY
• All audio processing runs 100% locally in your browser memory.
• ZERO telemetry, ZERO analytics, ZERO external server calls, ZERO tracking.
• No login or account required.

4. PRIVACY PRACTICES TAB (MANDATORY FOR CHROME STORE REVIEW APPROVAL)
--------------------------------------------------------------------------------

SINGLE PURPOSE DESCRIPTION:
"Volume Booster Pro amplifies tab audio up to 600% and provides equalizer sound profiles and sub-bass enhancement using the browser's native Web Audio API."

PERMISSIONS JUSTIFICATION (Copy & paste into Chrome Developer Dashboard):

1. tabCapture:
"Used exclusively to capture the audio output stream of the currently active media tab, route it through an AudioContext GainNode and DSP filters for amplification and equalization, and stream it to the user's speakers. No audio is ever recorded, saved, or transmitted to any external server."

2. storage:
"Used strictly to save user preferences locally, including active volume gain level, selected sound profile (EQ), sub-bass boost dB, and light/dark theme preference across browser sessions."

3. activeTab:
"Used to inspect the active tab's domain URL to display current media playback status in the extension popup and enable keyboard shortcut volume control on the active tab."

4. scripting:
"Used to inject lightweight helper scripts to coordinate media stream routing and handle playback state changes seamlessly."

5. offscreen:
"Used to run a persistent Web Audio API AudioContext pipeline in an isolated offscreen document so that boosted audio playback continues without interruption when the user closes the extension popup or navigates the active tab."

DATA USAGE & PRIVACY DECLARATION:
• Do you collect any personal data? NO
• Do you sell or transfer user data? NO
• Do you use user data for purposes unrelated to the extension's core functionality? NO
• Do you use user data for lending or creditworthiness? NO

OFFICIAL PRIVACY POLICY STATEMENT (URL or text):
"Volume Booster Pro does not collect, transmit, store, or sell any personal data, user analytics, audio recordings, or browsing history. All digital signal processing (DSP) and Web Audio API amplification occur strictly in local client memory on the user's machine. User preferences (gain level, EQ preset, theme) are stored exclusively in Chrome's local storage sandbox (chrome.storage.local) and never leave the device."
